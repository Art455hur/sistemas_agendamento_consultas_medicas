# Sistema de Agendamento de Consultas Médicas

Projeto acadêmico desenvolvido na disciplina de Programação Web. O sistema tem como objetivo facilitar o agendamento e o gerenciamento de consultas médicas.

## Problema

Pacientes podem enfrentar dificuldades para encontrar profissionais disponíveis, consultar horários e organizar seus agendamentos de maneira simples.

## Público-alvo

* Pacientes;
* Médicos;
* Recepcionistas;
* Clínicas e consultórios médicos.

## Proposta de solução

Desenvolver uma aplicação web simples e navegável que permita ao paciente pesquisar especialidades e profissionais, escolher uma data e um horário e acompanhar seus agendamentos.

## Principais funcionalidades

* Cadastro de pacientes;
* Login do usuário;
* Dashboard do paciente;
* Pesquisa por especialidade;
* Visualização dos médicos disponíveis;
* Escolha de data e horário;
* Confirmação do agendamento;
* Visualização das consultas agendadas;
* Cancelamento de consultas;
* Remarcação de consultas;
* Sistema de notificações;
* Navegação entre as páginas.

## Tecnologias utilizadas

## Tecnologias utilizadas

- CSS — estilização da aplicação;
- JavaScript — funcionamento e interatividade;
- React — criação das páginas e componentes;

- Git — controle de versão;

- PraxiLab — organização e acompanhamento das tarefas.

## Referências

O projeto utilizou como referências:

* [Hospital Samar](https://hospitalsamar.com.br/)
* [MedPrev](https://agendamento.medprev.online/)

As referências foram utilizadas para estudar o fluxo de agendamento, a organização das informações e a apresentação dos profissionais e horários.

## Como executar o projeto

## Como executar o projeto

1. Instale o Node.js;
2. Clone ou baixe este repositório;
3. Abra a pasta do projeto no Visual Studio Code;
4. Abra o terminal;
5. Instale as dependências:

   ```bash
   npm install
6. Execute o projeto:

   ```bash
   npm run dev
   ```

7. Acesse no navegador:

   ```text
   http://localhost:3000
   ```
