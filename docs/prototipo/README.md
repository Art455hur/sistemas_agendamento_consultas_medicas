# Protótipo do Sistema de Agendamento Médico

O protótipo foi desenvolvido no Figma Make com o objetivo de representar o fluxo principal do sistema de agendamento médico.

## Funcionalidades representadas

- Login do paciente
- Dashboard
- Busca por especialidade
- Seleção de médico
- Escolha de data e horário
- Confirmação do agendamento
- Visualização dos agendamentos
- Remarcação e cancelamento
- Painel de notificações
- Perfil do paciente

## Referências

- Hospital Samar
- MedPrev

O Samar foi utilizado como referência para o fluxo de agendamento, enquanto a MedPrev serviu como referência para a apresentação dos profissionais e horários disponíveis.

## Testes realizados

Foram testados o fluxo de agendamento, a navegação entre as páginas, as notificações e as funções de remarcar e cancelar consultas.
Também foram revisados o alinhamento dos elementos e a consistência entre nomes e imagens dos profissionais.
